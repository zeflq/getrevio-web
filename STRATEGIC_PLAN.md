# Getrevio Strategic Plan: Template Marketplace
**Version:** 2.0
**Date:** 2025-12-30
**Strategy:** Template Marketplace (Plan 4)

---

## 🎯 Executive Summary

**The Pivot:** From "gamification platform" to **"Template Marketplace for QR-activated landing pages"**

**The Product:** A platform where businesses choose from 15+ specialized templates, each optimized for specific use cases and niches.

**Competitive Positioning:**
- ❌ NOT competing with Myli.io on features (they have 4 tools, 5 years, enterprise sales)
- ✅ Competing on **breadth of templates** + **simplicity** + **pricing**

**The Analogy:**
- Myli = iPhone (does everything, expensive, complex)
- Getrevio = App Store (pick what you need, cheap, simple)

---

## 📊 Why Template Marketplace > Single Template

### Current State:
- 1 template (slot game) serving all use cases → limited TAM
- No differentiation from Myli's generic lottery
- Forced to compete on features (lose against enterprise)

### Template Marketplace Benefits:
1. ✅ **16 templates** (slot game + 15 new) vs Myli's 1 lottery → **competitive moat**
2. ✅ **Broader TAM** - Serve salons, dentists, real estate, insurance, not just restaurants
3. ✅ **Higher ACV** - Customers buy multiple templates (€29 for 1, €79 for 3, €149 unlimited)
4. ✅ **Lower churn** - More templates = more lock-in
5. ✅ **Clear positioning** - "Landing page templates" not "gamification"
6. ✅ **Hard to copy** - Breadth > depth (Myli can't build 16 templates easily)

### New: Template Registry System

**1. Add Metadata Type:**
```typescript
// templates/types.ts

export type TemplateMetadata = {
  id: string;
  category: "gamification" | "booking" | "lead-gen" | "ecommerce" | "survey" | "marketing" | "fundraising";
  pricingTier: "starter" | "professional" | "enterprise";
  targetNiches: string[];  // ["restaurants", "salons", "food-trucks"]
  previewImage: string;    // URL to preview screenshot
  isPublished: boolean;    // Control visibility in marketplace
  features: string[];      // ["Calendar integration", "SMS reminders"]
  demoUrl?: string;        // Optional live demo link
};

export type TemplateRegistryEntry = {
  definition: TemplateDefinition;
  meta: TemplateMeta;
  defaults: TemplateDefaults;
  metadata: TemplateMetadata;
};
```

**2. Create Template Registry:**
```typescript
// templates/registry.ts

import { slotTemplateDefinition } from "./definitions/slotTemplate";
import { slotTemplateMeta } from "./meta/slotTemplate.meta";
import { slotTemplateDefaults } from "./defaults/slotTemplate.defaults";

const TEMPLATE_REGISTRY = new Map<string, TemplateRegistryEntry>([
  [
    "slotTemplate",
    {
      definition: slotTemplateDefinition,
      meta: slotTemplateMeta,
      defaults: slotTemplateDefaults,
      metadata: {
        id: "slotTemplate",
        category: "gamification",
        pricingTier: "starter",
        targetNiches: ["restaurants", "cafes", "food-trucks", "bars"],
        previewImage: "/templates/previews/slot-game.png",
        isPublished: true,
        features: [
          "Gamified slot machine",
          "Reward fulfillment",
          "Review collection",
          "Instagram integration",
        ],
      },
    },
  ],
  // Future templates will be added here
]);

export const getTemplateRegistry = () => TEMPLATE_REGISTRY;

export const getPublishedTemplates = () => {
  return Array.from(TEMPLATE_REGISTRY.values()).filter(
    (entry) => entry.metadata.isPublished
  );
};

export const getTemplatesByCategory = (category: string) => {
  return Array.from(TEMPLATE_REGISTRY.values()).filter(
    (entry) => entry.metadata.category === category && entry.metadata.isPublished
  );
};

export const getTemplatesByNiche = (niche: string) => {
  return Array.from(TEMPLATE_REGISTRY.values()).filter(
    (entry) =>
      entry.metadata.targetNiches.includes(niche) && entry.metadata.isPublished
  );
};
```

**3. Update Public API:**
```typescript
// templates/index.ts (replace hardcoded switch)

import { getTemplateRegistry } from "./registry";
import { translateTemplate } from "./translation/translateTemplate";

export function getTemplateByIdForLocale(
  id: string | null | undefined,
  locale: string
): LandingTemplate | undefined {
  if (!id) return undefined;

  const registry = getTemplateRegistry();
  const entry = registry.get(id);

  if (!entry) return undefined;

  return translateTemplate(
    entry.definition,
    entry.meta,
    entry.defaults,
    locale
  );
}

export function getAllTemplatesForLocale(locale: string): LandingTemplate[] {
  const registry = getTemplateRegistry();

  return Array.from(registry.values())
    .filter((entry) => entry.metadata.isPublished)
    .map((entry) =>
      translateTemplate(entry.definition, entry.meta, entry.defaults, locale)
    );
}
```
